# EduKids

A playful bilingual learning site for toddlers, with a nature-and-friends homepage, ABC Garden, and Animal Friends.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The app is a static Vite frontend and can be deployed on Vercel. Client-side routes fall back to `index.html`.
